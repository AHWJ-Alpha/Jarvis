- 连续打开和关闭竖屏导航抽屉
- 对话、任务、工作区、设置页面切换

## 结果

- APK 安装和启动成功

- 页面切换、列表滚动和横屏布局正常
- 未发现控件重叠或应用崩溃
- `logcat` 未发现 `FATAL EXCEPTION`
- 测试结束后设备恢复竖屏

快速连续点击间隔小于动画时长时，第二次点击可能落在动画前的位置。这属于输入竞态，正常点击节奏下未复现。
