# Jarvis 插件管理

设置中的“插件管理”支持导入 OpenClaw JavaScript 插件 ZIP，也支持用主模型生成源码草稿。

## 生成并安装

1. 在 Jarvis 的“模型连接”中配置主模型。
2. 在“设置 → 插件管理”描述工具要做什么，点击“让 Jarvis 编写插件草稿”。
3. 检查工具名称和源码；需要时可直接编辑源码。
4. 点击“安装草稿（保持停用）”。
5. 检查已安装插件后，再打开开关并确认启用。Jarvis 会更新 OpenClaw 配置并重载 Gateway。

Jarvis 生成器针对不需要文件、进程、设备或网络访问的纯 JavaScript 工具；明显的动态执行/系统访问用法会被拒绝。静态检查不是安全沙箱，生成代码仍需审阅。

## 导入 ZIP

ZIP 可以直接包含插件文件，也可以再包一层单一目录。需包含：

- `openclaw.plugin.json`
- `package.json`
- 与 `package.json` `main` 字段对应的 `.js` 或 `.mjs` ESM 入口

两个清单中的插件 ID 和包名必须相同。当前只接受不需要额外 npm dependencies 的自包含包，解压上限 40 MB、入口源码上限 256 KB。导入成功后默认停用。

## 安全与限制

- OpenClaw 插件与 Gateway 同进程运行，当前没有独立进程级沙箱。
- 已启用插件可能访问 Gateway 环境数据、联网，并调用 Gateway 可用的 Jarvis 设备工具；最终设备能力仍受 Jarvis 当前配置和权限状态影响。
- 启用前必须确认风险并审阅来源/源码；停用或卸载会重载 Gateway。
- 插件包不会自动获得系统权限，也不会自动打开 root 完全模式。
