# Android arm64 OpenClaw runtime bundle

This directory documents the artifact expected by Jarvis. Build the artifact on a reproducible Android arm64 toolchain, then place the resulting archive at:

`app/src/main/assets/openclaw/runtime.bundle.zip`

Required archive entries:

- `node`: executable Android bionic Node.js, version 24.x compatible with OpenClaw.
- `openclaw.mjs`: OpenClaw `2026.9.7` entrypoint.
- `node_modules/`: dependencies installed for Android arm64, including any native modules.

The archive is intentionally not generated by a desktop `npm install`. Desktop Linux binaries are not valid Android binaries. Validate on a rooted arm64 device before distributing an APK. Keep the archive out of Git when it is larger than the repository policy; use a release artifact or private CI storage and copy it into `app/src/main/assets` during the release build.
